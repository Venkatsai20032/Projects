A consolidated repository containing miscellaneous Jupyter Notebooks exploring exploratory data analysis (EDA), data cleaning, statistical modeling, and machine learning implementations.

---

## 📂 Contents Overview
* **Exploratory Data Analysis (EDA)**: Cleaning features, plotting correlations, detecting outliers, and generating descriptive charts.
* **Supervised Learning**: Notebooks implementing regression (linear, multiple) and classification (Logistic Regression, Decision Trees).
* **Unsupervised Learning**: Implementation of clustering algorithms (K-Means, Hierarchical) to find dataset patterns.
* **Data Processing Workflows**: Outlier removal, missing value imputation, scaling, and categorical variable encoding.

---

## ⚙️ Setup and Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Venkatsai20032/Projects.git
   ```
2. Install dependencies:
   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn jupyter
   ```
3. Run the notebook environment:
   ```bash
   jupyter notebook
   ```
